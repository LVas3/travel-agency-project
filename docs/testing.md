# Тестирование

## Виды тестов

### Модульные тесты

Файл `server/tests/test_auth.py` проверяет функции хеширования и проверки пароля.

Файл `server/tests/test_repositories.py` проверяет CRUD-операции двух реализаций Repository:

- `TourRepositoryOrm` — работа через SQLAlchemy ORM;
- `TourRepositorySql` — работа через прямые SQL-запросы.

### Сквозные тесты

Файл `server/tests/test_api.py` проверяет пользовательские сценарии через HTTP API:

- регистрация и авторизация;
- запрет неверной роли;
- создание, поиск, обновление и удаление тура через ORM;
- создание, поиск, обновление и удаление тура через SQL;
- полный сценарий: регистрация клиента → создание тура → бронирование → просмотр бронирования → отзыв.

## Изоляция тестовой БД

В `server/tests/conftest.py` используется отдельная SQLite база `test_travel_agency.db` через переменную окружения `TRAVEL_AGENCY_DATABASE_URL`. Рабочий файл `travel_agency.db` при тестах не изменяется.

## Запуск

```bash
python -m pytest -q server/tests
```
